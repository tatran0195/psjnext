## Introduction

**PSJ-Utility** is used for querying model’s information. It is used to complement what is missing from the Macro or
PSJ-Command. For example:

- [`JPT.Debugger()`](./psj-utility/JPT.Debugger) : Console debugger for PSJ. This utility will show all the related
  information of the inputted value to the Python API window
- [`JPT.Exec()`](./psj-utility/JPT.Exec) : Run Jupiter macro
- [`JPT.GetAllParts()`](./psj-utility/JPT.GetAllParts) : Get information of all parts
- [`JPT.GetMaxIDEntity()`](./psj-utility/JPT.GetMaxIDEntity) : Get max ID of entity from DItem type
- [`JPT.GetSelectedElems()`](./psj-utility/JPT.GetSelectedElems) : Get all information of the selected elements
- [`JPT.ViewFitToModel()`](./psj-utility/JPT.ViewFitToModel) : Change the view of the current model to fit with the
  Jupiter display window

It is written in the form of: **`JPT.Function_Name(parameters)`**
