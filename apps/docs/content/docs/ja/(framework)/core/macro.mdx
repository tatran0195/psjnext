## Introduction

**Macro** is equivalent to Jupiter built-in dialog function, but without a

<a data-tip="Graphical User Interface">GUI</a>. For example:

- `CreateCube([0, 0, 0], [10, 10, 10], [10, 10, 10], "Cube_1", 7105764, 0:0)` : Make a cube with default input values
- `ImprintLineS([[7.8, 0, 10], [2.2, 10, 10]], [6:26], 1)` : Imprint a line on a face between 2 points

It is generated right after a dialog function successfully runs.

![PSJ Macro - Animation](/docs/PSJ_structure_macro_V5.1.1.gif)

Macro can be recorded, run, save and reload using the **Macro window**. In the below picture, from left to right is:
Macro Load, Save, Record, Rewind, Play, Next, Stop, Tool, ViewPoint:

![PSJ Macro - Record and Reload](/docs/PSJ_structure_macro_V5.png)
