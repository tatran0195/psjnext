## Description

Move Nodes from Node to 3 nodes created Plane

## Syntax

```psj
MeshEdit.MoveNode.ProjectToPlane _3Nodes(ilNodeList=[])
```

## Inputs

<!-- @since:5.0.1 @optional -->
### ilNodeList

- Specify the node list.
- The default value is \[].

## Return Code

A String of 1 if success, or 0 if fail.

## Sample Code

```psj
MeshEdit.MoveNode.ProjectToPlane _3Nodes(ilNodeList=[])
```
