## Description

Mesh Copy Pattern

## Syntax

```psj
MeshEdit.MeshCopy(crlFaces=[], crlNodes=[])
```

## Inputs

<!-- @since:5.0.1 @optional -->
### crlFaces

- Specify the face.
- The default value is \[].

<!-- @since:5.0.1 @optional -->
### crlNodes

- Specify the node.
- The default value is \[].

## Return Code

A String of 1 if success, or 0 if fail.

## Sample Code

```psj
MeshEdit.MeshCopy(crlFaces=[], crlNodes=[])
```
