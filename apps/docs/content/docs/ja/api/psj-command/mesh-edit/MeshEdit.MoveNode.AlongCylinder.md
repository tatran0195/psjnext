## Description

Move node along cylinder surface

## Syntax

```psj
MeshEdit.MoveNode.AlongCylinder(crlFaces=[], crlNodes=[], dIrX=0, dIrY=0, dIrZ=0, dCircleX=0, dCircleY=0, dCircleZ=0, dRadius=0, dHeight=0)
```

## Inputs

<!-- @since:5.0.1 @optional -->
### crlFaces

- Specify the face.
- The default value is \[].

<!-- @since:5.0.1 @optional -->
### crlNodes

- Specify the node.
- The default value is \[].

<!-- @since:5.0.1 @optional -->
### dIrX

- Specify the direction x.
- The default value is 0.

<!-- @since:5.0.1 @optional -->
### dIrY

- Specify the direction y.
- The default value is 0.

<!-- @since:5.0.1 @optional -->
### dIrZ

- Specify the direction z.
- The default value is 0.

<!-- @since:5.0.1 @optional -->
### dCircleX

- Specify the circle x.
- The default value is 0.

<!-- @since:5.0.1 @optional -->
### dCircleY

- Specify the circle y.
- The default value is 0.

<!-- @since:5.0.1 @optional -->
### dCircleZ

- Specify the circle z.
- The default value is 0.

<!-- @since:5.0.1 @optional -->
### dRadius

- Specify the radius.
- The default value is 0.

<!-- @since:5.0.1 @optional -->
### dHeight

- Specify the height.
- The default value is 0.

## Return Code

A String of 1 if success, or 0 if fail.

## Sample Code

```psj
MeshEdit.MoveNode.AlongCylinder(crlFaces=[], crlNodes=[], dIrX=0, dIrY=0, dIrZ=0, dCircleX=0, dCircleY=0, dCircleZ=0, dRadius=0, dHeight=0)
```
