## Description

Element Conversion

## Syntax

```psj
MeshEdit.ElementConvert(crlParts=[], iType=1)
```

## Inputs

<!-- @since:5.0.1 @optional -->
### crlParts

- Specify the part.
- The default value is \[].

<!-- @since:5.0.1 @optional -->
### iType

- Specify the type.
- The default value is 1.

## Return Code

A String of 1 if success, or 0 if fail.

## Sample Code

```psj
MeshEdit.ElementConvert(crlParts=[], iType=1)
```
