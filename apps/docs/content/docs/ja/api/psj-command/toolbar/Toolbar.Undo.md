## Description

Undo

## Syntax

```psj
Toolbar.Undo(iCntUndo=1)
```

## Inputs

<!-- @since:5.0.1 @optional -->
### iCntUndo

- Specify the cnt undo.
- The default value is 1.

## Return Code

A String of 1 if success, or 0 if fail.

## Sample Code

```psj
Toolbar.Undo(iCntUndo=1)
```
