## Description

Cut for ACModeling

## Syntax

```psj
ACModeling.Cut(...)
```

## Inputs

<!-- @since:5.0.1 @required -->
### crlParts

- Specify the part.

## Return Code

A String of 1 if success, or 0 if fail.

## Sample Code

```psj
ACModeling.Cut(crlParts)
```
