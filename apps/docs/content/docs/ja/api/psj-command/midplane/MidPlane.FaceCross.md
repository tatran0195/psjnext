## Description

Face Cross

## Syntax

```psj
MidPlane.FaceCross(crlBodies=[], crlFaces=[])
```

## Inputs

<!-- @since:5.0.1 @optional -->
### crlBodies

- Specify the bodies.
- The default value is \[].

<!-- @since:5.0.1 @optional -->
### crlFaces

- Specify the faces.
- The default value is \[].

## Return Code

A String of 1 if success, or 0 if fail.

## Sample Code

```psj
MidPlane.FaceCross(crlBodies=[], crlFaces=[])
```
