## Description

Align mid-nodes

## Syntax

```psj
SZOnepushReliability.AlignMidNode(crlSource, crlTargets)
```

## Inputs

<!-- @since:5.0.1 @required -->
### crlSource

- Specify the source.

<!-- @since:5.0.1 @required -->
### crlTargets

- Specify the target.

## Return Code

A String of 1 if success, or 0 if fail.

## Sample Code

```psj
SZOnepushReliability.AlignMidNode(crlSource, crlTargets)
```
