## Description

Renumber connection

## Syntax

```psj
Tools.Connections(listConnectRenumberTool)
```

## Inputs

<!-- @since:5.0.1 @required -->
### listConnectRenumberTool

- Specify the connect renumber tool.

## Return Code

A String of 1 if success, or 0 if fail.

## Sample Code

```psj
Tools.Connections(listConnectRenumberTool)
```
