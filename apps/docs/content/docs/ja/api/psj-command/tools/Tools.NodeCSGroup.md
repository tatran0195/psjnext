## Description

Create a node group in the nodal coordinate system.

## Syntax

```psj
Tools.NodeCSGroup()
```

## Inputs

None.

## Return Code

A String of 1 if success, or 0 if fail.

## Sample Code

```psj
Tools.NodeCSGroup()
```
