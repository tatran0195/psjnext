## Description

Displace coordinate

## Syntax

```psj
Tools.DisplacementCS(crlInst=[], crCoordSystem=None)
```

## Inputs

<!-- @since:5.0.1 @optional -->
### crlInst

- Specify the inst.
- The default value is \[].

<!-- @since:5.0.1 @optional -->
### crCoordSystem

- Specify the coordinate system.
- The default value is None.

## Return Code

A String of 1 if success, or 0 if fail.

## Sample Code

```psj
Tools.DisplacementCS(crlInst=[], crCoordSystem=None)
```
