## Description

Delete Entity in Group

## Syntax

```psj
Tools.Group.DeleteGroupEntity(crlGroups)
```

## Inputs

<!-- @since:5.0.1 @required -->
### crlGroups

- Specify the del group.

## Return Code

A String of 1 if success, or 0 if fail.

## Sample Code

```psj
Tools.Group.DeleteGroupEntity(crlGroups)
```
