## Description

Cleanup element edge by swap

## Syntax

```psj
MeshCleanup.Manual3D.Swap(crplElemEdge)
```

## Inputs

<!-- @since:5.0.1 @required -->
### crplElemEdge

- Specify the element edge.

## Return Code

A String of 1 if success, or 0 if fail.

## Sample Code

```psj
MeshCleanup.Manual3D.Swap(crplElemEdge)
```
