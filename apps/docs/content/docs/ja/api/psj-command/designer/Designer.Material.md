## Description

Create a material.

## Syntax

```psj
Designer.Material(strMatName, strPropName, dThickness, crlTargets)
```

## Inputs

<!-- @since:5.0.1 @required -->
### strMatName

- Specify the material name.

<!-- @since:5.0.1 @required -->
### strPropName

- Specify the property name.

<!-- @since:5.0.1 @required -->
### dThickness

- Specify the thickness.

<!-- @since:5.0.1 @required -->
### crlTargets

- Specify the target.

## Return Code

A String of 1 if success, or 0 if fail.

## Sample Code

```psj
Designer.Material(strMatName, strPropName, dThickness, crlTargets)
```
