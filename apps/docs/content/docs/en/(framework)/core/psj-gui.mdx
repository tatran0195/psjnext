## Introduction

**PSJ-GUI** is an UI library supporting user making dialog fast and easily.
For example:

- `dlg.add_label(name="Label30",text="Average Size",width=100,text_halign="left",text_valign="top",layout="Layout29")` : Add a text label
- `dlg.add_textbox(name="Aver_size",layout="Layout29")` : Add a text edit box

Different from other Python UI packages (e.g. _PyQT_, _Tkinter_, _PySide_, etc.), PSJ-GUI is **fully integrating into Jupiter’s UI framework**,
help making user’s function same look & feel as Jupiter’s built-in dialog function.

![PSJ GUI](/docs/PSJ_structure_gui.png)

PSJ-GUI also supports **2-ways connection**, e.g. model picking, table, tab/wizard, etc.

## GUI Command Builder

**GUI Command Builder** is an interactive builder of PSJ-GUI, help making Jupiter dialog or wizard by **Drag & Drop operations**.
User hence does not need to know Python programming language to make UI components in Jupiter.

![PSJ GUI](/docs/PSJ_GUI_Command_Builder_V5.1.1.gif)
