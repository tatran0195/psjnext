## Description

Renumber connection

## Syntax

```psj
Tools.Connections(listConnectRenumberTool)
```

## Inputs

### `listConnectRenumberTool` @type(CONNECT\_RENUMBER\_TOOL List) @required

- The connect renumber tool.

## Return Code

A String of 1 if success, or 0 if fail.

## Sample Code

```psj
Tools.Connections(listConnectRenumberTool)
```
