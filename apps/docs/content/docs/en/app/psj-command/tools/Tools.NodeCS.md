## Description

Create Node CS

## Syntax

```psj
Tools.NodeCS(crlInst=[], crCoordSystem=None)
```

## Inputs

### `crlInst` @type(List\[Cursor]) @default(\[])

- The inst.

### `crCoordSystem` @type(Cursor) @default(None)

- The coordinate system.

## Return Code

A String of 1 if success, or 0 if fail.

## Sample Code

```psj
Tools.NodeCS(crlInst=[], crCoordSystem=None)
```
