## Description

Cleanup element edge by swap

## Syntax

```psj
MeshCleanup.Manual3D.Swap(crplElemEdge)
```

## Inputs

### `crplElemEdge` @type(Cursor Pair List) @required

- The element edge.

## Return Code

A String of 1 if success, or 0 if fail.

## Sample Code

```psj
MeshCleanup.Manual3D.Swap(crplElemEdge)
```
