## Description

Undo

## Syntax

```psj
Toolbar.Undo(iCntUndo=1)
```

## Inputs

### `iCntUndo` @type(Integer) @default(1)

- The cnt undo.

## Return Code

A String of 1 if success, or 0 if fail.

## Sample Code

```psj
Toolbar.Undo(iCntUndo=1)
```
