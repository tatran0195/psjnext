## Description

Face Cross

## Syntax

```psj
MidPlane.FaceCross(crlBodies=[], crlFaces=[])
```

## Inputs

### `crlBodies` @type(List\[Cursor]) @default(\[])

- The bodies.

### `crlFaces` @type(List\[Cursor]) @default(\[])

- The faces.

## Return Code

A String of 1 if success, or 0 if fail.

## Sample Code

```psj
MidPlane.FaceCross(crlBodies=[], crlFaces=[])
```
