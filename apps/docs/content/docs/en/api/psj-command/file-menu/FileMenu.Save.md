## Description

Save file JTDB

## Syntax

```psj
FileMenu.Save(strFileName="")
```

## Inputs

<!-- @since:5.0.1 @type:String @optional @default:"" -->
### `strFileName`

- The file name.

## Return Code

A String of 1 if success, or 0 if fail.

## Sample Code

```psj
FileMenu.Save(strFileName="")
```
