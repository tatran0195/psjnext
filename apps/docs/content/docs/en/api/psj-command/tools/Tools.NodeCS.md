## Description

Create Node CS

## Syntax

```psj
Tools.NodeCS(crlInst=[], crCoordSystem=None)
```

## Inputs

<!-- @since:5.0.1 @type:List[Cursor] @optional @default:[] -->
### `crlInst`

- The inst.

<!-- @since:5.0.1 @type:Cursor @optional @default:None -->
### `crCoordSystem`

- The coordinate system.

## Return Code

A String of 1 if success, or 0 if fail.

## Sample Code

```psj
Tools.NodeCS(crlInst=[], crCoordSystem=None)
```
