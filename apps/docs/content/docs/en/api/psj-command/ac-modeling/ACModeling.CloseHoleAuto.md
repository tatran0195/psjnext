## Description

ACModeling CloseHoleAuto

## Syntax

```psj
ACModeling.CloseHoleAuto(...)
```

## Inputs

<!-- @since:5.0.1 @type:List[Cursor] @required -->
### `crlClosedHoleParts`

- The closed hole parts.

## Return Code

A String of 1 if success, or 0 if fail.

## Sample Code

```psj
ACModeling.CloseHoleAuto(crlClosedHoleParts)
```
