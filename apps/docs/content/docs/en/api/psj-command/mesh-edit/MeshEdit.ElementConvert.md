## Description

Element Conversion

## Syntax

```psj
MeshEdit.ElementConvert(crlParts=[], iType=1)
```

## Inputs

<!-- @since:5.0.1 @type:List[Cursor] @optional @default:[] -->
### `crlParts`

- The part.

<!-- @since:5.0.1 @type:Integer @optional @default:1 -->
### `iType`

- The type.

## Return Code

A String of 1 if success, or 0 if fail.

## Sample Code

```psj
MeshEdit.ElementConvert(crlParts=[], iType=1)
```
