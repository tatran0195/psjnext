## Description

Mirror copy of surface mesh

## Syntax

```psj
MeshEdit.MirrorCopy(crlFaces=[])
```

## Inputs

<!-- @since:5.0.1 @type:List[Cursor] @optional @default:[] -->
### `crlFaces`

- The face.

## Return Code

A String of 1 if success, or 0 if fail.

## Sample Code

```psj
MeshEdit.MirrorCopy(crlFaces=[])
```
