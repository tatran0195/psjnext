## Description

Move node by equalize

## Syntax

```psj
MeshEdit.MoveNode.Equalize(crlEdges=[])
```

## Inputs

<!-- @since:5.0.1 @type:List[Cursor] @optional @default:[] -->
### `crlEdges`

- The edge.

## Return Code

A String of 1 if success, or 0 if fail.

## Sample Code

```psj
MeshEdit.MoveNode.Equalize(crlEdges=[])
```
