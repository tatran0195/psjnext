## Description

Face Cross

## Syntax

```psj
MidPlane.FaceCross(crlBodies=[], crlFaces=[])
```

## Inputs

- The bodies.

<!-- @since:5.0.1 @type:List[Cursor] @optional @default:[] -->
### `crlFaces`

A String of 1 if success, or 0 if fail.
