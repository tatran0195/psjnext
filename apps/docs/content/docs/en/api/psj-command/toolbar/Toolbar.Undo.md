## Description

Undo

## Syntax

```psj
Toolbar.Undo(iCntUndo=1)
```

## Inputs

<!-- @since:5.0.1 @type:Integer @optional @default:1 -->
### `iCntUndo`

- The cnt undo.

## Return Code

A String of 1 if success, or 0 if fail.

## Sample Code

```psj
Toolbar.Undo(iCntUndo=1)
```
