## Description

Align mid-nodes

## Syntax

```psj
SZOnepushReliability.AlignMidNode(crlSource, crlTargets)
```

## Inputs

<!-- @since:5.0.1 @type:List[Cursor] @required -->
### `crlSource`

- The source.

<!-- @since:5.0.1 @type:List[Cursor] @required -->
### `crlTargets`

- The target.

## Return Code

A String of 1 if success, or 0 if fail.

## Sample Code

```psj
SZOnepushReliability.AlignMidNode(crlSource, crlTargets)
```
