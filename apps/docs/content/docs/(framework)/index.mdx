## Background problems in daily CAE work

- Repeated operations can make CAE user **boring and uncomfortable**.
- The iterative work without automation **cannot be completed within a desired duration**.
- Manual operation by human can **create mistakes**.
- **In depth CAE trainings** can be required if modelling is complicated.
- Each firm has its own design rule/process, design specification/template, etc. thus **customized UI specific to each user** will be more convenient and helpful.

![Target users](/docs/target_users.png)

## PSJ: for automation and customization

To solve the above problems and meet the requirements from our diverged users, PSJ (Python Scripting for Jupiter) is developed, with our **4F moto**:

![4F moto](/docs/benefit_V5.0.1.png)

### Notable features

With PSJ, you would have these below features:

1. Jupiter functions in **Python script**
    - Incorporate with Jupiter’s powerful Pre/Post functions
    - Connect with other software
    - Compatible with Python 3.x and its vast libraries

2. **GUI Command Builder**: Easy creation of GUI dialog equivalent to Jupiter built-in's
3. **Customized IDE**: With powerful predicting tips, programming support functions
4. **Customized Shell**: Error output for debugging
