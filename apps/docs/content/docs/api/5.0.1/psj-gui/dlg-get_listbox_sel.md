## Description

Get the index of the selecting ListBox option.

## Syntax

```psj
dlg.get_listbox_sel(...)
```

## Inputs

### `name`

- A _String_ specifying the name of the ListBox component.
- This is a required input.

## Return Code

An _Integer_ specifying the index of the being selected ListBox option.
