## Description

Change the "Enable" option of an inputted component to off (Disabled).

## Syntax

```psj
dlg.disable_item(...)
```

## Inputs

### `name`

- A _String_ specifying the name of the component.
- This is a required input.

## Return Code

This function does not have output value.
