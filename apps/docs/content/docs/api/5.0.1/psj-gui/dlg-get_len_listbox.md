## Description

Get the size (number of items) of the ListBox.

## Syntax

```psj
dlg.get_len_listbox(...)
```

## Inputs

### `name`

- A _String_ specifying the name of the ListBox component.
- This is a required input.

## Return Code

An _Integer_ specifying the size of the ListBox component.
