## Description

Set event when selecting a cell.

## Syntax

```psj
dlg.on_table_sel_changed(...)
```

## Inputs

### `name`

- A _String_ specifying the name of Table.
- This is a required input.

### `callfunc`

- The name of function wants to be bound to.
- This is a required input.

## Return Code

This function does not have output value.
