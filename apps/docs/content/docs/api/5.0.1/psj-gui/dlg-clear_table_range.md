## Description

Clear content of the specific range by position in the Table.

## Syntax

```psj
dlg.clear_table_range(...)
```

## Inputs

### `name`

- A _String_ specifying the name of Table.
- This is a required input.

### `cell_range`

- A _[TableCellRange](/docs/cli/5.0.1/data-type/psj-gui/TableCellRange)_ object specifying the information of a specific range (multi cells).
- This is a required input.

## Return Code

This function does not have output value.
