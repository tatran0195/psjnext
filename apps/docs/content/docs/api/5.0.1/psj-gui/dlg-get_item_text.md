## Description

Get text inside the component.

## Syntax

```psj
dlg.get_item_text(...)
```

## Inputs

### `name`

- A _String_ specifying the name of the component which user want to get text.
- This is a required input.

## Return Code

A _String_ specifying the text inside the component.
