## Description

Set an image to the ImageCtrl.

## Syntax

```psj
dlg.set_image_file(...)
```

## Inputs

### `name`

- A _String_ specifying the name of the ImageCtrl component.
- This is a required input.

### `image_path`

- A _String_ specifying the full path of the image.
- This is a required input.

## Return Code

This function does not have output value.
