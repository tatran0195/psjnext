## Description

Get the total number of rows of the Table.

## Syntax

```psj
dlg.get_total_row(...)
```

## Inputs

### `name`

- A _String_ specifying the name of the Table component.
- This is a required input.

## Return Code

An _Integer_ specifying the total number of rows of the Table.
