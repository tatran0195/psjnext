## Description

Get the information and attributes of the selected cells.

## Syntax

```psj
dlg.get_table_sel_cell(...)
```

## Inputs

### `name`

- A _String_ specifying the name of Table.
- This is a required input.

## Return Code

- A _[TableCellVector](/docs/cli/5.0.1/data-type/psj-gui/TableCellVector)_ object or _List of [TableCellID](/docs/cli/5.0.1/data-type/psj-gui/TableCellID)_ specifying the methods of cells.
