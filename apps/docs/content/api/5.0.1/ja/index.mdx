## これは何ですか？

Fumadocs Core は、Next.js などの React.js フレームワーク上でドキュメントサイトを構築するための、サーバーサイド関数とヘッドレスコンポーネントを提供します。

- 検索（内蔵: Orama、Algolia Search）
- パンくずリスト、サイドバー、目次（TOC）コンポーネント
- Remark / Rehype プラグイン
- 追加ユーティリティ

<Callout title="ヒント">

    Fumadocs UI を使わずに利用することも可能です。つまり、ヘッドレスとして使えます。

    初心者や一般的な用途では、[Fumadocs UI](/docs/ui) の使用をおすすめします。

</Callout>
