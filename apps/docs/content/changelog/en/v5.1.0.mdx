:::tip[Highlight updates]

Version 5.1 brings major updates focused on **enhancing Post-processing functionality** and **strengthening
visualization and automation features**. Significant improvements have been made to PSJ Commands, macros, GUI
operations, and PSJ Utilities-resulting in greater scripting control and more intuitive operation.

In detail:

- Full PSJ Command Support for Post-processing
- Enhanced Visualization and Drawing Capabilities
- More Flexible Material Handling
- Improved PSJ-GUI Interactivity
- New APIs and DItemTypes for Result Handling
- Enhanced Scripting and Automation
- Updates to Macros and PSJ Commands

:::
