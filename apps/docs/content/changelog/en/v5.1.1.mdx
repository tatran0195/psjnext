:::tip[Highlight updates]

Version 5.1.1 continues to update new functions for both Pre-processing and Post-processing. New improvements have been
made to PSJ Commands, macros, and PSJ Utilities-resulting in greater scripting control and more intuitive operation.

In detail:

- New PSJ Command for Durability and other Post-processing
- New PSJ Command for Exchange and other Pre-processing
- Restructuring Macro/PSJ command of Elem Related Info
- Updates to Macros, PSJ Commands and PSJ Utility
- Enhanced Scripting and Automation

:::

## 🐛 Bug Fix

### ⚙ Macro

- Fix the bug where the macro `CleanupAuto` not working if cleanup target was a list of elements.
- Fixed bug where the macro `MeasureMassByProperty` working incorrectly resulting in incorrect measured mass by property

### ⌘ PSJ-Command

#### 📝 API

- Fix the bug where the command `Tools.DisplacementCS` not working as expected.
- Fix the bug where the command `Connections.RigidElements.RBE2.OneToOneNodesWithTolerance` and
  `Connections.RigidElements.RBar.OneToOneNodesWithTolerance` querying Master/Slave node ID incorrectly.
- Fixed the bug where the `Calculation.StrainGauge.TangentProjection` command argument printing wrong value compared to
  GUI value.

### 📐 PSJ-GUI

#### 📅 GUI Command Builder

- Fixed the bug where clicking the `GroupBox` title bar unexpectedly opened a command dialog.

### 🛠 PSJ-Utility

#### 📝 API

- Fix the bug where the utility `JPT.GetAllResultsByElemId` cannot get specific data.
- Fix the bug where the utility `JPT.EnableLicenseFeature` cannot disable the license.
