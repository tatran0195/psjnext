#### 📝 API

API commands related to database query are added:

<details>
<summary>List of newly added commands</summary>

- `JPT.GetProgramVersion()` : Get Jupiter current release number.
- `JPT.GetContactType()` : Get Abaqus contact type.

## <ChangelogBadge variant="fix">Bug Fix</ChangelogBadge> Bug Fix

- After importing a Parasolid file (in foreground and background mode), if a part or _[DItem](/docs/data-type/psj-utility/pre-utility/built-in-types/DItem)_ with Japanese name in the assembly tree, Jupiter cannot read, put into `part.name` and print out. For example:

```psj
parts = JPT.GetAllParts()
for part in parts:
    print(part.name)
```

- Jupiter crashes when `PYTHONHOME` and `PYTHONPATH` are set by other software.
