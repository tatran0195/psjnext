:::tip 主なアップデート本リリースは主にPSJ-Utilityの改善に焦点を当て、いくつかの機能強化とバグ修正を含んでいます。

- 新しいデータ型を追加
- 新しいPSJ-Utilityコマンド（API）とサンプルを追加

:::

## 🚀 新機能

### 📦 データ型

- _[DBody](./../data-type/psj-utility/pre-utility/built-in-types/DBody)_（`vertexs`、`colorMesh`、`transparance`）、_[DEdge](./../data-type/psj-utility/pre-utility/built-in-types/DEdge)_（`color`）、_[DFace](./../data-type/psj-utility/pre-utility/built-in-types/DFace)_（`color`）、_[DNode](./../data-type/psj-utility/pre-utility/built-in-types/DNode)_（`isFloating`）、_[DElem](./../data-type/psj-utility/pre-utility/built-in-types/DElem)_（`kind`、`color`）に新しいプロパティを追加。
- 新しい*[関連付けタイプ](./../data-type/psj-utility/pre-utility/enumeration-types/associate-types)_、_[ブールタイプ](./../data-type/psj-utility/pre-utility/enumeration-types/bool-types)_、_[エンティティタイプ](./../data-type/psj-command/DItem-types)_、_[パスタイプ](./../data-type/psj-utility/pre-utility/enumeration-types/path-types)*を追加。
- 新しいリストクラス*[DItemVector](./../data-type/psj-utility/pre-utility/built-in-types/DItemVector)_、_[BodyVector](./../data-type/psj-utility/pre-utility/built-in-types/BodyVector)_、_[FaceVector](./../data-type/psj-utility/pre-utility/built-in-types/FaceVector)_、_[ElemVector](./../data-type/psj-utility/pre-utility/built-in-types/ElemVector)_、_[GroupVector](./../data-type/psj-utility/pre-utility/built-in-types/GroupVector)_、_[NodeVector](./../data-type/psj-utility/pre-utility/built-in-types/NodeVector)_、_[EdgeVector](./../data-type/psj-utility/pre-utility/built-in-types/EdgeVector)*を追加。

### 🛠 PSJ-Utility

#### 📝 API

データベースクエリ、キャスト、表示に関連するAPIコマンドが追加されました：

<details>
<summary>新しく追加されたコマンドのリスト</summary>

- `addObj()` : 現在のリストに値を追加。
- `clearVec()` : すべてのリストをクリア → clearVec使用後のリストのサイズは0になります。
- `deleteObj()` : インデックスを入力してリストのオブジェクトを削除。
- `extendVec()` : 選択されたリストに別のリストを追加。
- `isContainObj()` : 入力されたオブジェクトが現在のリストに存在するかどうかを確認。
- `JPT.CastDItemToDBody()` : DItemをDBodyに変換して、選択されたボディの情報を取得。
- `JPT.CastDItemToDEdge()` : DItemをDEdgeに変換して、選択されたエッジの情報を取得。
- `JPT.CastDItemToDElem()` : DItemをDElementに変換して、選択された要素の情報を取得。
- `JPT.CastDItemToDFace()` : DItemをDFaceに変換して、選択された面の情報を取得。
- `JPT.CastDItemToDGroup()` : DItemをDGroupに変換して、選択されたDGroupの情報を取得。
- `JPT.CastDItemToDNode()` : DItemをDNodeに変換して、選択されたDNodeの情報を取得。
- `JPT.CastToDItem()` : 選択されたものをDItemに変換して、すべての関連情報を取得。
- `JPT.ClearLog()` : Python APIウィンドウに存在するすべてのテキストをクリア。
- `JPT.ConvertJPTColorToRGB()` : JupiterのカラーコードをRGB値に変換。
- `JPT.ConvertRGBToJPTColor()` : RGB値をJupiterのカラーコードに変換。
- `JPT.Debugger()` : 入力されたパラメータのすべての関連情報（値、クラスなど）をPython APIウィンドウに表示。
- `JPT.DItemListToMacroListTCursor()` : DItemリストをマクロリストカーソルに変換。
- `JPT.GetAppPathInfo()` : 選択されたパスタイプの情報を取得。
- `JPT.GetElemsByKind()` : 入力された要素タイプのすべての関連情報を取得。
- `JPT.GetEntitiesByAdjacent()`
  : 入力された条件（角度）で入力されたエンティティに関連するすべてのエンティティ（面/要素）を取得。
- `JPT.GetEntitiesByAssociation()` : 入力された条件で入力されたターゲットに関連するすべてのエンティティを取得。
- `JPT.GetEntitiesByID()` : 入力されたエンティティとそのIDのすべての関連情報を取得。
- `JPT.GetEntitiesByName()` : 入力された条件に類似した名前（Option = 0）または完全に同じ名前（Option =
  1）を持つエンティティのすべての関連情報を取得。
- `JPT.GetEntitiesByPosition()` : 入力された条件と等しいまたは同じ座標を持つエンティティのすべての関連情報を取得。
- `JPT.GetMaxIDEntity()` : 入力されたエンティティタイプの最大IDを取得。
- `JPT.GetMinIDEntity()` : 入力されたエンティティタイプの最小IDを取得。
- `JPT.GetPythonAPILog()` : Python APIウィンドウに存在するテキストを取得。
- `JPT.GetRandomJPTColor()` : Jupiterでランダムなカラーコード（整数値）を取得。
- `JPT.InverseHideBodies()` : 表示ウィンドウで入力されたアイテムのみを表示。
- `JPT.ListDoubleToMacroVector()` : 値のリストをマクロタイプの文字列に変換。
- `JPT.MacroListTCursorToListDItem()` : マクロタイプの文字列をDItemVectorタイプに変換。
- `JPT.PrintAppPathInfo()` : 現在のモデルファイルのすべての関連情報をPython
  APIウィンドウに表示（プログラムパス、tempパス、appdataパス、ドキュメントパス（jtdbパス）を含む）。
- `JPT.PrintPSJUtilityManual()` : Python APIウィンドウで既存のすべてのPython API関数とその情報を表示。
- `JPT.QuitApplication()` : Jupiterを終了。
- `JPT.RemoveEntitiesByID()` : 入力されたエンティティタイプとそのIDを削除。
- `JPT.RemoveEntitiesByName()` : 入力された値に類似した名前（Option 3 = 0）または完全に同じ名前（Option 3 =
  1）を含むすべてのエンティティを削除。
- `JPT.ShowHideAllParts()` : モデル上の既存のすべてのパーツを表示/非表示。
- `JPT.ShowHideEntitiesByID()` : 入力されたアイテムIDを表示/非表示。
- `JPT.ViewFitToModel()` : 現在のビューをモデルに合わせて変更。

</details>
