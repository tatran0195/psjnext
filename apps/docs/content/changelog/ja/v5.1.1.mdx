:::tip[Highlight updates]

バージョン 5.1.1 は、プリプロセスおよびポストプロセスの両方に対する新機能の更新を継続しています。PSJ コマンド、マクロ、PSJ ユーティリティに新しい改善が加えられ、スクリプト制御が強化され、より直感的な操作が可能になりました。

詳細:

- 耐久性およびその他のポストプロセス用の新しい PSJ コマンド
- 交換およびその他のプリプロセス用の新しい PSJ コマンド
- 要素関連情報のマクロ/PSJ コマンドの再構成
- マクロ、PSJ コマンド、PSJ ユーティリティの更新
- スクリプトと自動化の強化

:::

## 🐛 バグ修正

### ⚙ マクロ

- マクロ `CleanupAuto` が、クリーンアップ対象が要素リストの場合に動作しない不具合を修正しました。
- マクロ `MeasureMassByProperty` が誤った質量を測定する不具合を修正しました。

### ⌘ PSJ-Command

#### 📝 API

- コマンド `Tools.DisplacementCS` が期待通りに動作しない不具合を修正しました。
- コマンド `Connections.RigidElements.RBE2.OneToOneNodesWithTolerance` および
  `Connections.RigidElements.RBar.OneToOneNodesWithTolerance`
  が Master/Slave 節点ID を誤って取得する不具合を修正しました。
- コマンド `Calculation.StrainGauge.TangentProjection` の引数が GUI 値と異なる値を出力する不具合を修正しました。

### 📐 PSJ-GUI

#### 📅 GUI コマンドビルダー

- `GroupBox` タイトルバーをクリックすると予期せずコマンドダイアログが開く不具合を修正しました。

### 🛠 PSJ-Utility

#### 📝 API

- ユーティリティ `JPT.GetAllResultsByElemId` が特定のデータを取得できない不具合を修正しました。
- ユーティリティ `JPT.EnableLicenseFeature` がライセンスを無効化できない不具合を修正しました。
