:::tip[Highlight updates]

ハイライト情報このリリースは主に PSJ-ユーティリティと PSJ-GUI の改善に焦点を当てており、少数の機能強化とバグ修正が行われています。

- 新しい PSJ-ユーティリティコマンド（API）を追加
- 新しい PSJ-GUIコマンド（API）を追加
- GUIコマンドビルダーに高度なコントロールを追加

:::

## 🚀 新機能

### 🛠 PSJ-ユーティリティ

#### 📝 API

データベースクエリ、変更に関連するAPIコマンドが追加されました:

<details>
<summary>新しく追加されたコマンドのリスト</summary>

- `JPT.CheckLicense()` : 入力されたライセンスが有効化されているかどうかをチェックします。
- `JPT.ClearRedo()` : 保存されているすべてのやり直し手順をクリアします。
- `JPT.ClearUndo()` : 保存されているすべての元に戻す手順をクリアします。
- `JPT.ConvertFromDocUnit()` : ユーザーの単位をSI単位系に変換します。
- `JPT.ConvertFromMacroUnit()` : ユーザーの単位をマクロ単位系に変換します。
- `JPT.ConvertValueToDocUnit()` : SI単位系をユーザーの単位に変換します。
- `JPT.ConvertValueToMacroUnit()` : マクロ単位系をユーザーの単位に変換します。
- `JPT.CopyToClipBoard()` : 現在のビューのスクリーンショットを撮影してウィンドウクリップボードに保存します。
- `JPT.CreateSubAssembly()` : サブアセンブリを自動的に作成します。
- `JPT.DeleteSubAssembly()` : すべての関連情報を含む入力されたサブアセンブリを削除します。
- `JPT.Exec()` : この関数にマクロを入力することで Jupiter マクロを実行します。
- `JPT.FindSubAssemblyByID()` : 入力されたアセンブリIDのすべての関連情報を取得します。
- `JPT.FindSubAssemblyByName()` : 入力されたアセンブリ名のすべての関連情報を取得します。
- `JPT.GetAllByTableTypeID()`
  : 入力されたテーブルタイプIDのすべての情報を取得します（現在の使用可能なテーブルタイプIDを確認するには、ユーザーは
  `JPT.Debugger(JPT.DTableType.values)` を使用できます）。
- `JPT.GetAllByType()`
  : 入力されたタイプIDのすべての情報を取得します（現在の使用可能なタイプIDを確認するには、ユーザーは
  `JPT.Debugger(JPT.EntityType.values)` を使用できます）。
- `JPT.GetAllEdges()` : モデル上に存在するすべてのエッジの情報を取得します。
- `JPT.GetAllElems()` : モデル上に存在するすべての要素の情報を取得します。
- `JPT.GetAllFaces()` : モデル上に存在するすべてのフェースの情報を取得します。
- `JPT.GetAllGroups()` : モデル上に存在するすべてのグループの情報を取得します。
- `JPT.GetAllLoadsBCs()` : モデル上に存在するすべての境界条件の情報を取得します。
- `JPT.GetAllNodes()` : モデル上に存在するすべての節点の情報を取得します。
- `JPT.GetAllParts()` : モデル上に存在するすべてのパーツの情報を取得します。
- `JPT.GetAllPartsInSubAssembly()` : 入力されたアセンブリに属しているパーツの関連情報を取得します。
- `JPT.GetAllSelected()` : 選択されたすべてのアイテム（パーツ、節点、要素など）の情報を取得します。
- `JPT.GetCenterOfEntities()` : 選択したエンティティの中心を取得します。
- `JPT.GetCountByType()` : 入力されたタイプの合計数を取得します。
- `JPT.GetCurrentDocumentPath()` : 現在の Jupiter ファイルのパスを取得します。
- `JPT.GetJPTTempPath()` : Jupiter の一時フォルダーのリンクを取得します。
- `JPT.GetLastCreatedCursor()` : 最後に作成されたカーソルとその関連情報を取得します。
- `JPT.GetMacroLog()` : マクロウィンドウに存在するテキストを取得します。
- `JPT.GetMaterialDBById()` : 入力された材料IDの材料データベース内の材料IDを取得します。
- `JPT.GetMaterialXML()` : 材料データベース内のすべての材料情報を取得します。
- `JPT.GetOpnList()` :
  Jupiter のすべての機能を取得します（それぞれのGUI モデルを持った利用可能な Jupiter 機能を確認するには、ユーザーは
  `JPT.Debugger(JPT.DTableType.values)` を使用できます）。
- `JPT.GetProgramPath()` : Jupiter のインストールフォルダのパスを取得します。
- `JPT.GetRedoCount()` : 現在のモデル上に存在するすべてのリドゥ手順を取得します。
- `JPT.GetSelectedEdges()` : 選択されたエッジの情報を取得します。
- `JPT.GetSelectedEdgesCr()` : 選択されたエッジのIDを取得します。
- `JPT.GetSelectedElems()` : 選択された要素の情報を取得します。
- `JPT.GetSelectedElemsCr()` : 選択された要素のIDを取得します。
- `JPT.GetSelectedFaces()` : 選択されたフェースの情報を取得します。
- `JPT.GetSelectedFacesCr()` : 選択されたフェースのIDを取得します。
- `JPT.GetSelectedGroups()` : 選択されたグループの情報を取得します。
- `JPT.GetSelectedGroupsCr()` : 選択されたグループのIDを取得します。
- `JPT.GetSelectedNodes()` : 選択された節点の情報を取得します。
- `JPT.GetSelectedNodesCr()` : 選択された節点のIDを取得します。
- `JPT.GetSelectedParts()` : 選択されたパーツの情報を取得します。
- `JPT.GetSelectedPartsCr()` : 選択されたパーツのIDを取得します。
- `JPT.GetSharedElements()` : 入力された条件に関連する共有要素の情報を取得します。
- `JPT.GetSharedFaces()` : 入力された条件に関連する共有面の情報を取得します。
- `JPT.GetSharedNodes()` : 入力された条件に関連する共有節点の情報を取得します。
- `JPT.GetUndoCount()` : 元に戻す手順の総数を取得します。
- `JPT.MsgOut()` : 入力されたテキストを Python API ウィンドウに出力します。
- `JPT.RemoveAllAbaqusStep()` : 現在のモデル上からすべての Abaqus ステップを削除します。
- `JPT.RemoveAllByTableType()` : 入力されたテーブルタイプのすべての関連アイテムを削除します。
- `JPT.RemoveAllConnections()` : 現在のモデル上のすべての接続を削除します。
- `JPT.RemoveAllContacts()` : 現在のモデル上のすべてのコンタクトを削除します。
- `JPT.RemoveAllCoordinates()` : 現在のモデル上のすべての座標を削除します。
- `JPT.RemoveAllFieldTables()` : 現在のモデル上のすべてのフィールドデータテーブルを削除します。
- `JPT.RemoveAllLoadCases()` : 現在のモデル上のすべての荷重ケースを削除します。
- `JPT.RemoveAllLoadsBCs()` : 現在のモデル上のすべての境界条件を削除します。
- `JPT.RemoveAllMaterials()` : 現在のモデル上のすべての材料を削除します。
- `JPT.RemoveAllMeshSettings()` : 現在のモデル上のすべてのメッシュ設定を削除します。
- `JPT.RemoveAllSolverjob()` : 現在のモデル上のすべてのソルバージョブを削除します。
- `JPT.RemoveWSProperties()` : 現在のモデル上のすべてのプロパティを削除します。

</details>

### 📐 PSJ-GUI

#### 📝 API

セレクタ、ブラウザ、ページコントロール、テーブルに関するAPIコマンドが追加されました:

<details>
<summary>新しく追加されたコマンドのリスト</summary>

- `dlg.add_1delement_selector()` : ダイアログに1D要素セレクタを追加し、1D要素のみを選択できます。
- `dlg.add_2delement_selector()` : ダイアログに2D要素セレクタを追加し、2D要素のみを選択できます。
- `dlg.add_3delement_selector()` : ダイアログに3D要素セレクタを追加し、3D要素のみを選択できます。
- `dlg.add_barpart_selector()` : ダイアログにバーパーツセレクタを追加し、バーパーツのみを選択できます。
- `dlg.add_edge_selector()` : ダイアログにエッジセレクタを追加し、エッジのみを選択できます。
- `dlg.add_elementedge_selector()` : ダイアログに要素エッジセレクタを追加し、要素エッジのみを選択できます。
- `dlg.add_face_selector()` : ダイアログにフェースセレクタを追加し、フェースのみを選択できます。
- `dlg.add_node_selector()` : ダイアログに節点セレクタを追加し、節点のみを選択できます。
- `dlg.add_part_selector()` : ダイアログにパーツセレクタを追加し、パーツのみを選択できます。
- `dlg.add_vertex_selector()` : ダイアログに頂点セレクタを追加し、頂点のみを選択できます。
- `dlg.add_browser()` : ダイアログにファイル/フォルダーブラウザコンポーネントを追加します。
- `dlg.add_pagesctrl()` : ダイアログにページコントロールコンポーネントを追加します。
- `dlg.add_pagesctrl_page()` : 既存のページコントロールに新しいページウィンドウを追加します。
- `dlg.add_table()` : ダイアログにテーブルコンポーネントを追加します。

</details>

#### 📏 GUIコマンドビルダー

- データベースの保存を開くを追加
- 先進的なUIコントロールを追加: ファイル/フォルダーを開く、テーブル、ウィザード。
