:::tip[Highlight updates]

アップデートのハイライトこのリリースでは主に PSJ-GUI の開発に焦点を当て、GUI コマンドビルダーを導入します。

:::

## 🚀 新機能

### 📐 PSJ-GUI

#### 📝 API

コンボボックス、リストボックス、グループボックス、スライダー、レイアウトなどに関連する API コマンドが追加されました：

<details>
<summary>新しく追加されたコマンドのリスト</summary>

- `dlg.add_space()` : プレースホルダーを追加します。
- `dlg.disable_item()` : コンポーネントを無効にします。
- `dlg.enable_item()` : コンポーネントを有効にします。
- `dlg.get_combobox_sel()` : コンボボックスの現在選択中のインデックスを取得します。
- `dlg.get_item_text()` : コンポーネントウィンドウのテキストを取得します。
- `dlg.get_len_combobox()` : コンボボックスのオプション数を取得します。
- `dlg.get_len_listbox()` : リストボックスのオプション数を取得します。
- `dlg.get_listbox_sel()` : リストボックスの現在選択中のインデックスを取得します。
- `dlg.hide_layout()` : レイアウトとそれに含まれるすべてのコンポーネントを非表示にします。
- `dlg.insert_combobox_option()` : 指定した位置にオプションを挿入します。
- `dlg.insert_combobox_options()` : 指定した位置にオプション配列を挿入します。
- `dlg.insert_listbox_option()` : 指定した位置にオプションを挿入します。
- `dlg.insert_listbox_options()` : 指定した位置にオプション配列を挿入します。
- `dlg.isbutton_checked()` : チェックボックスがチェックされているかどうかを判定します。
- `dlg.set_checkbox_state()` : チェックボックスをチェックまたは非チェックに設定します。
- `dlg.set_combobox_sel()` : コンボボックスの現在の選択を設定します。
- `dlg.set_image_file()` : 画像ファイルを imagectrl に設定して表示します。
- `dlg.set_item_text()` : コンポーネントウィンドウのテキストを設定します。
- `dlg.set_listbox_sel()` : リストボックスの選択を設定します。
- `dlg.set_popup_menu()` : テーブル内のポップアップメニューの設定をします。
- `dlg.add_button()` : ダイアログにボタンコンポーネントを追加します。
- `dlg.add_checkbox()` : ダイアログにチェックボックスコンポーネントを追加します。
- `dlg.add_combobox()` : ダイアログにコンボボックスコンポーネントを追加します。
- `dlg.generate_window()` : ダイアログを生成して表示します。
- `dlg.on_command()` : コンポーネントをユーザー定義関数に接続します。
- `dlg.add_groupbox()` : ダイアログにグループボックスコンポーネントを追加します。
- `dlg.set_groupbox_checked()` : グループボックスを右上隅でチェック済みにします。
- `dlg.set_groupbox_collapsed()` : グループボックスを折りたたみます。
- `dlg.set_groupbox_orientation()` : グループボックスのレイアウト方向を水平または垂直に設定します。
- `dlg.add_imagectrl()` : ダイアログに画像コントロールコンポーネントを追加します。
- `dlg.add_label()` : ダイアログにラベルコンポーネントを追加します。
- `dlg.add_hlayout()` : 水平レイアウトを追加します。
- `dlg.add_vlayout()` : 垂直レイアウトを追加します。
- `dlg.add_listbox()` : ダイアログにリストボックスコンポーネントを追加します。
- `dlg.add_radiobutton()` : ダイアログにラジオボタンコンポーネントを追加します。
- `dlg.add_richeditbox()` : ダイアログにリッチエディットボックスコンポーネントを追加します。
- `dlg.add_separator()` : ダイアログにセパレータコンポーネントを追加します。
- `dlg.add_slider()` : ダイアログにスライダーコンポーネントを追加します。
- `dlg.set_slider_bothtics()` : スライダーコンポーネントの両側に目盛りを表示または非表示にします。
- `dlg.set_slider_show_border()` : スライダーコンポーネントの枠線を表示または非表示にします。
- `dlg.set_slider_show_tics()` : 目盛りの表示または非表示を設定します。
- `dlg.set_slider_vertical()` : スライダーを垂直または水平方向に設定します。
- `dlg.add_spin()` : ダイアログにスピンコンポーネントを追加します。
- `dlg.add_tabwnd()` : ダイアログにタブコンポーネントを追加します。
- `dlg.add_tabwnd_page()` : 既存のタブコンポーネントにタブページを追加します。
- `dlg.add_textbox()` : ダイアログにテキストボックスコンポーネントを追加します。

</details>
