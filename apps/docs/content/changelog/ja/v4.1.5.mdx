:::tip[Highlight updates]

ハイライト更新このリリースは、主にパフォーマンスの向上に焦点を当て、いくつかの機能強化とバグ修正が行われています。

:::

## 🚀 新機能

### 🛠 PSJ-Utility

#### 📝 API

データベースクエリに関連するAPIコマンドが追加されました：

<details>
<summary>新しく追加されたコマンドの一覧</summary>

- `JPT.GetProgramVersion()` : Jupiterの現在のリリース番号を取得します。
- `JPT.GetContactType()` : Abaqusの接触タイプを取得します。

</details>

## 🐛 バグ修正

- Parasolidファイルをインポートした後（前景モードと背景モード）、組立ツリーに日本語名のパートまたは
  _[DItem](/docs/data-type/psj-utility/pre-utility/built-in-types/DItem)_
  がある場合、Jupiterは読み取ることができず、`part.name`に格納して出力することができません。例：

```psj
parts = JPT.GetAllParts()
for part in parts:
    print(part.name)
```

- 他のソフトウェアによって`PYTHONHOME`と`PYTHONPATH`が設定されている場合、Jupiterがクラッシュします。
