:::tip[Highlight updates]

V5.0.4では、主に表示操作を強化するためのAPI機能を追加しました。また、新機能や新オプション用にマクロやPSJ
Commandを更新しています。

- OOBB配置（新機能）コントロール用の新規データタイプ、マクロ、APIを追加しました。
- パーツ外観表示を変更するマクロ・APIを追加しました。
- ライセンス状況をより簡単に確認できるマクロ・APIを追加しました。
- 画像キャプチャマクロ・APIに、画像トリミングのオプションを追加しました。
- 値を取得するAPIに、表示中のエンティティのみに限定するオプションを追加しました。

:::

### 🛠 PSJ-Utility

#### 📝 API

- 新規に10個のAPIコマンドを追加しました。

<details>

<summary>新規追加API一覧</summary>- `JPT.GetAllPostNodes` : 全てのPost節点 （読み取り専用）を取得します。
Postドキュメントでのみ動作します。 - `JPT.GetAllPostElems` : 全てのPost要素 （読み取り専用）を取得します。
Postドキュメントでのみ動作します。 - `JPT.EnableAllLicenses` : 利用可能なすべてのライセンスを有効にします。 -
`JPT.GetAllContacts` : 全ての存在する接触情報を取得します。 - `JPT.GetAllLicensesStatus` :
すべてのライセンス状態を取得します。 - `JPT.GetInternalIDRefItem`: 参照エンティティの内部IDを取得します。 -
`JPT.GetResultTitle`: 結果がロードされているとき、タイトルの内容を取得します。 - `JPT.GetScreenHeight` :
メインウィンドウの高さを取得します。 - `JPT.GetScreenPositionOfEntities` :
指定したエンティティのメインウィンドウ内での位置を取得します。 - `JPT.GetScreenWidth` :
メインウィンドウの幅を取得します。

</details>

        - `JPT.GetMaxResultValue` : 表示されているエンティティについてのみ値を取得できるようにしました。

## 🐛 不具合修正

### ⌘ PSJ-Command

- Measureコマンドが指定された値と異なる精度を返す不具合を修正しました。
- Tools.TotalLoadコマンドが間違った値を返すことがある不具合を修正しました。

### 📐 PSJ-GUI

#### 📝 API

- DNODEクラスのisFloatingアトリビュート確認時に時間がかかる問題を修正しました。

#### 📏 GUI Command Builder

- `RichEditControl` のデフォルトテキストが \*.jdb ファイルを再読み込みしたときに保持されない不具合を修正しました。
- `Spin` のdouble型のプロパティが \*.jdb ファイルを再読み込みした際に保持されない不具合を修正しました。

### 🛠 PSJ-Utility

#### 📝 API

- Postドキュメントで`JPT.GetAllByTypeID()`を使用した場合、POST_NODEおよびPOST_ELEMタイプに対して間違った値を返す不具合を修正しました。
- DNODEクラスのisFloating属性をチェックするのに時間がかかる問題を修正しました。
- `JPT.GetMaxIDEntity()`が誤った値を返す不具合を修正しました。

### ⚙ Macro

- DeleteFaceマクロが引数としてエンティティの内部IDを要求する不具合を修正しました。
- いくつかのケースでMeasureTotalLoad\_マクロが誤った値を返す不具合を修正しました。
